# 手制光谱仪数据可视化分析项目总结

本项目旨在辅助化学实验 "Shedding Light on the Structure of the Atom" 的数据分析环节，通过读取手制光谱仪上观测到的刻度数据，自动进行光谱仪校准、未知样本的光谱波长转换、元素匹配，并生成直观的数据可视化图表。

## 1. 项目模块结构

项目共划分为以下五个核心文件：

- **`config.py` (配置与数据中心)**
  将所有已知的物理常量和光谱数据集中管理，便于后续添加新元素。

  - `HG_STANDARD_WAVELENGTHS`: 汞灯标准波长列表。
  
  - `HG_STANDARD_COLORS`: 汞灯可见光颜色描述（Violet, Blue 等）。
  - `KNOWN_ELEMENTS_SPECTRA`: 候选元素的特征光谱波长字典（H, He, Ar, Ne等）。
  
- **`spectrometer.py` (光谱仪硬件模拟)**
  封装了 `Spectrometer` 类，代表一台“虚拟光谱仪”。负责接收汞灯的测量数据，运用最小二乘法进行线性拟合 $y = kx + b$，得到度数到波长的转换模型，并计算 $R^2$ 拟合优度。校准后，负责将其他未知样本的度数转换为标准波长。

  `class Spectrometer`:

  - 属性: `k`, `b`, `r_squared`, `is_calibrated`
  - 方法 `calibrate(measured_degrees)`: 接收汞灯的测量刻度，计算并存储拟合参数（迁移原 `calibrate_spectrometer` 逻辑）。
  - 方法 `degrees_to_wavelengths(degrees)`: 将读数转换为波长。

- **`analyzer.py` (光谱匹配算法)**
  核心的分析模块，封装了 `SpectrumAnalyzer` 类。基于 **DTW (Dynamic Time Warping，动态时间规整)** 算法计算测量光谱序列与已知元素标准光谱序列之间的“距离”。DTW 能够有效处理观测谱线遗漏或杂散光导致的多余谱线问题，找到最佳匹配的元素成分。算法通过除以序列最大长度（`max(len(measured), len(ref))`）来进行距离标准化，确保结果的公平性。

  - **计算 DTW 距离**
  	对于每一对序列 $(X, Y_k)$，用动态规划计算累计距离矩阵 $D$：
  
  	- 初始化 $D[0][0] = 0$, $D[i][0] = \infty$, $D[0][j] = \infty$。
  	- 递推公式：
  	  $$D[i][j] = d(x_i, y_j) + \min(D[i-1][j], D[i][j-1], D[i-1][j-1])$$
  	- 最终 DTW 距离为 $\text{DTW}(X, Y_k) = D[n][l_k]$，其中 $l_k$ 为 $Y_k$ 的长度。
  
  - **选择最匹配序列**
     计算 $X$ 与所有 $Y_k \in \mathcal{T}$ 的 DTW 距离，选出距离最小的序列：
     $$Y^* = \arg \min_{Y_k \in \mathcal{T}} \text{DTW}(X, Y_k)$$
  
- **`visualization.py` (GUI 与可视化绘图)**
  交互界面与可视化渲染模块。
  - 基于 `tkinter` 提供数据输入的弹窗 UI，支持动态不定长数据的快捷输入（空格或逗号分隔）。
  - 基于 `matplotlib` 提供精美的可视化输出，包含校准用的“散点-拟合曲线图”，以及判定样本成分时使用的“样本 vs 参考元素”上下比对光谱图（带可见光背景渲染）。

- **`__main__.py` (主程序入口)**
  作为整个分析过程的调度中心，串联上述所有模块，控制程序的标准运行工作流。

  1. 提示输入汞灯 7 条谱线的读数。
  2. 拟合出刻度-波长的转换模型并展示校准曲线（含 $R^2$ 评估）。
  3. 循环 4 次弹窗提示输入样本读数（可用空格或逗号自由分隔多条读数）。
  4. 自动通过 DTW 算法匹配元素，控制台输出各项评分。
  5. 弹窗展现上下对比的光谱图（样本光谱对比最匹配参考光谱）。

## 2. 完整的分析工作流 (Process)

运行 `python __main__.py` 后，程序将严格按照以下两阶段流程执行：

### 阶段一：光谱仪校准 (Calibration)
1. **输入汞灯读数**：程序弹出窗口，提示用户依次输入汞灯 7 条可见光特征谱线在手制光谱仪上对应的观测度数。
2. **线性拟合**：提取 `config.py` 中的汞灯标准波长，通过 `spectrometer.py` , 实例化 `Spectrometer` 并调用 `calibrate()`, 进行多项式线性拟合，计算斜率 $k$ 与截距 $b$。
3. **输出图表**：调用 `plot_calibration_curve()`, 控制台打印校准公式与 $R^2$，同时绘制出校准散点及拟合曲线图，供用户确认光谱仪的读数线性度是否良好。

### 阶段二：样本测量与匹配 (Sample Matching)
该阶段会自动循环 4 次，以测量 4 个未知样本：
1. **录入样本读数**：程序弹出一个含大型文本框的窗口，用户可将观察到的任意数量的样本光谱读数一次性填入（使用空格或逗号隔开即可）。
2. **读数转换**：将样本度数数据传入已校准的 `Spectrometer` 对象，依据拟合公式转换为实际波长序列。
3. **DTW 算法比对**：将转换后的波长序列送入 `analyzer.py`，遍历已知候选元素库，计算并评估两序列之间的归一化 DTW 距离，得分最小者即得出匹配度最高的候选元素。
4. **可视化比对输出**：调用 `visualization.py` 中的`plot_comparison_spectrum()`绘制“发射光谱比对图”。图表上方展示实测样本的光谱线分布，下方展示匹配出元素的标准特征光谱线分布，辅助用户直观地完成实验报告的论证。
